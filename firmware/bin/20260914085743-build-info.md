## Flashing

From the `firmware/` directory (ports per `firmware/README.md`; on CH343-bridge clones the port is `/dev/ttyACM*`, see NOTES):

```bash
espflash flash --port /dev/ttyACM0 bin/20260914085743-firmware-a
espflash flash --port /dev/ttyACM1 bin/20260914085743-firmware-q
espflash flash --port /dev/ttyACM2 bin/20260914085743-firmware-p
```

Do NOT flash `qemu/target/.../oee-qemu` — a different target (LM3S6965/Cortex-M3); it will not boot on an ESP32-S3.
