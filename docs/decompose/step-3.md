## Д1 (пн, ~3 ч) — движок: shape-folding парсер

1. Пасс нормализации §2.1: таблица «тензор → виртуальная форма»; `EXPAND_DIMS`/
   `RESHAPE` не порождают код; цепочка Flatten `SHAPE → STRIDED_SLICE → PACK →
   RESHAPE` вычисляется статически и сворачивается в один виртуальный reshape.
2. Rank-3 вход/выход §2.2: `(1, T, C)` нормализуется до `(1, 1, T, C)`.
3. Юнит-тесты парсера на фактическом графе спайка: `conv1d.tflite` положить в
   `fork/microflow/models/` (по прецеденту `dense_spike.tflite`).
4. Ошибки: несворачиваемое — `abort_call_site!` с сообщением «какой op, какая форма,
   что ожидаем» (§2.1), не паника без контекста.

Проверка: свёртка графа спайка даёт ровно 6 слоёв — CONV_2D, AVERAGE_POOL_2D,
CONV_2D, AVERAGE_POOL_2D, FULLY_CONNECTED, SOFTMAX.

## Д2 (вт, ~3 ч) — движок: операторы и кодеген

1. Операторы §2.3: `CONV_2D` с валидацией `h == 1` (иначе — существующий путь
   conv_2d), `AVERAGE_POOL_2D` с фильтром `(1, p)`, `FULLY_CONNECTED` c
   `inputs.len() == 2` → константный нулевой bias (F6), `SOFTMAX`.
2. Квантование §2.4: per-channel у CONV_2D уже есть (`TokenTensor4D`, QUANTS = F);
   FC — QUANTS > 1, если §3.3 не сделан (см. Д0), иначе per-tensor флагом в
   ml-скрипте — решение зафиксировать одной строкой в NOTES.
3. Кодеген §4: вход rank-3 → `predict()` принимает `Buffer2D<f32, T, C>`
   (нулевое копирование); ассерты `h == 1`, `T ≥ k` (valid), размеры буферов;
   `target/microflow-expansion.rs` — для ревью кодегена.
4. Compile-fail тесты: неправильная модель → читаемая ошибка компиляции.

Проверка: модель спайка (необученная) собирается через `#[model]`; expansion
читается и понятен.

## Точки эскалации

- Парсер не тянет фактический граф (вне §2.1) → сначала правка спеки, потом код;
  если граф изменился версией TF — перегенерировать дамп `build_conv1d_model.py`,
  обновить спайк-док и спеку.
- Parity расходится сильнее ±1 квант → разбирать послойно: промежуточные тензоры
  interpreter против expansion-кода; сначала CONV_2D-блоки, потом FC.
- Точность int8 просела >2% против float → зафиксировать в отчёте; QAT — future
  work (разд. 12), сейчас не отвлекаться.
- Обучение плохое на сырых окнах → один эксперимент: фичи как каналы (C > 1);
  помнить: вход `(128, 1)` уже поддержан парсером, C > 1 — расширение.
- FC per-channel не реализован (§3.3) → per-tensor флагом в train-скрипте; факт —
  в NOTES и отчёт.
