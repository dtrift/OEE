| Компонент                      | Узел | Назначение                        |

| Серво SG90 + палочка 10–15 см  | Q    | Механизм удара                    |
| TCRT5000 × 2                   | P    | Счёт деталей + датчик конца ленты |

### Механика и расходники

| Компонент                                          | Примечание                                       |
| -------------------------------------------------- | ------------------------------------------------ |
| Конвейер 100×350 мм (0–116 об/мин)                 | С регулятором скорости                           |
| Дрель или вентилятор + болт M5                     | «Станок» — нагрузка дисбаланса                   |
| Гайки/шайбы M5–M8 (~50 шт.)                        | Детали, катающиеся по ленте                      |
| «Брак» — распилленные/ сколотые детали (10–15 шт.) | Помечены маркером, ground truth для узла Q       |
| Макетная плата MB-102 (830 точек) × 1–4            | По одной на узел — удобнее                       |
| Провода jumper M-M / M-F                           | Белый = сигналы, жёлтый = I2S, синий = серво PWM |
| Электролитический конденсатор 470 мкФ              | На питании серво                                 |
| Блок питания 5 В 2 А (отдельный)                   | Только для серво — не делить шину 5 В с платами  |
| USB-C кабели с данными × 3                         | Должны быть data, не charge-only                 |

### Что проверять при заказе

- На модуле должна быть маркировка **N16R8** (16 MB flash + 8 MB octal PSRAM). Клоны с N8R2 (2 MB PSRAM) маловаты для камеры и роли запасной платы.
- Два USB-C порта на плате — native OTG и UART bridge.
- Клоны с AliExpress подходят; референс — шелкография `ESP32-S3-DevKitC-1`.

## 2. Справочник пинов плат

**Единый источник правды:** `firmware/board/src/lib.rs`. Изменения в wiring делаются здесь, а не в прошивках узлов.

### Узел A — Ток (ACS712)

| Сигнал                          | GPIO | ADC      | Примечание                            |
| ------------------------------- | ---- | -------- | ------------------------------------- |
| ACS712 OUT (после делителя 2:1) | 4    | ADC1_CH3 | Только ADC1 — ADC2 конфликтует с WiFi |

### Узел Q — Звук + Серво

| Сигнал         | GPIO | Примечание  |
| -------------- | ---- | ----------- |
| I2S SCK (BCLK) | 12   | INMP441     |
| I2S WS (LRCL)  | 13   | INMP441     |
| I2S SD         | 14   | INMP441     |
| Серво PWM      | 11   | 50 Гц, LEDC |

### Узел P — ИК-счёт (CAM плата)

| Сигнал       | GPIO | Примечание                                        |
| ------------ | ---- | ------------------------------------------------- |
| TCRT5000 OUT | 5    | CAM плата — убедиться, что пин свободен от камеры |

### Запрещённые пины (не использовать)

```
GPIO 0, 3, 45, 46   — strapping
GPIO 19, 20         — USB D−/D+
GPIO 35, 36, 37     — octal PSRAM на N16R8
GPIO 43, 44         — UART0 / console
```

### Цветовая дисциплина проводов

| Цвет      | Назначение                  |
| --------- | --------------------------- |
| Красный   | +5 В (только питание серво) |
| Оранжевый | +3,3 В                      |
| Чёрный    | GND                         |
| Белый     | Сигналы (ADC, ИК, PWM)      |
| Жёлтый    | Линии I2S                   |
| Синий     | Сигнал серво                |

**Критично:** Никогда не соединяйте плюсы двух источников 5 В вместе. Соединяются только минусы (GND).

## 5. Схема подключений

### 5.1 Узел A — Датчик тока

ACS712-20A выдаёт 2,5 В при нулевом токе. Пины ESP32-S3 НЕ являются 5 В-терпимыми, поэтому делитель 2:1 обязателен.

**Подключение модуля ACS712:**

| Пин ACS712 | Подключение                                |
| ---------- | ------------------------------------------ |
| VCC        | 5 В платы (красный провод → нижняя + шина) |
| GND        | GND платы (чёрный провод → − шина)         |
| OUT        | → 10 кОм → GPIO4 → 10 кОм → GND            |

**Расположение на макетной плате (строки 20–22):**

```
Строка 20: ACS712 OUT --[10 кОм]-- Строка 21
Строка 21: --[10 кОм]-- Строка 22 → перемычка на (−) шину
Строка 21 (точка отвода): → провод (белый) → GPIO4 платы
```

**Проверка мультиметром до подачи USB:** между проводом GPIO4 и GND должно быть ~1,2–1,3 В при выключенном станке (ноль ACS712).

**Включение ACS712 в цепь станка:** разорвите цепь низковольтного питания станка (только ≤36 В!), включите ACS712 последовательно: `БП 12 В → IP+ ... IP- → вентилятор`. **Не подключайте к сети 220 В.**

### 5.2 Узел Q — Микрофон + Серво

**Подключение INMP441:**

| Пин INMP441 | Подключение                               |
| ----------- | ----------------------------------------- |
| VDD         | 3,3 В (оранжевый провод → верхняя + шина) |
| GND         | GND (чёрный провод → − шина)              |
| SCK (BCLK)  | GPIO12 (жёлтый провод)                    |
| WS (LRCL)   | GPIO13 (жёлтый провод)                    |
| SD          | GPIO14 (жёлтый провод)                    |
| L/R         | GND (перемычка на соседнюю строку GND)    |

Держите провода I2S короче 15 см для снижения помех.

**Подключение серво (отдельный блок питания 5 В — НЕ USB платы):**

| Пин SG90           | Подключение                                   |
| ------------------ | --------------------------------------------- |
| Сигнал (оранжевый) | GPIO11 (синий провод)                         |
| Плюс (красный)     | Отдельный БП 5 В +                            |
| Минус (коричневый) | Отдельный БП 5 В − И GND платы (общий ground) |

**Конденсатор 470 мкФ:** между +5 В и GND серво на макетной плате. Длинная ножка (плюс) в строку 8, короткая (полоска) в строку 10.

### 5.3 Узел P — ИК-барьер (CAM плата)

**Подключение модуля TCRT5000:**

| Пин TCRT5000 | Подключение                               |
| ------------ | ----------------------------------------- |
| VCC          | 3,3 В (оранжевый провод → верхняя + шина) |
| GND          | GND (чёрный провод → − шина)              |
| OUT          | GPIO5 (белый провод)                      |

**Настройка потенциометром:**
1. Лента пустая, питание включено: крутите до тех пор, пока светодиод «Detection OFF» не загорится стабильно.
2. Пропустите гайку через зазор: светодиод «Detection» мигает при каждом проходе.
3. Если светодиод горит постоянно: увеличьте расстояние или экранируйте излучатель от отражений.
4. Если светодиод не реагирует: уменьшите расстояние.

Если модуль инвертирован (OUT высокий при пустом зазоре), исправьте в `firmware/p/src/main.rs` — не в счётчике.

## 6. Порядок сборки

Соблюдайте эту последовательность с проверками на каждом шаге:

### Шаг 1: Механика
- Соберите конвейер по инструкции комплекта.
- Закрепите «станок» (дрель/вентилятор с болтом M5) на начале ленты.
- Отметьте позицию тапа на 2/3 длины ленты.
- **Проверка:** лента движется от блока питания; напряжение блока соответствует маркировке мотора.

### Шаг 2: Пустая макетная плата
- Соедините верхнюю (−) шину с нижней (−) перемычкой.
- **Проверка:** прозвонка top(−) ↔ bottom(−) ≈ 0 Ом.

### Шаг 3: Узел A
- Соберите делитель ACS712 на строках 20–22.
- Подключите провода к GPIO4 и шинам питания платы.
- **Проверка:** только USB, станок выключен → `a: zero=NNN` в мониторе UART.

### Шаг 4: Узел Q
- Установите INMP441 через центральную канавку (строки 1–5).
- Подключите блок серво (строки 8–12) с отдельным БП и конденсатором 470 мкФ.
- **Проверка:** меандр 50 Гц на GPIO11 (осциллограф/логический анализатор).

### Шаг 5: Узел P
- Установите модуль TCRT5000 на строки 30–32.
- Настройте потенциометр по индикатору светодиода.
- **Проверка:** стабильный OUT на пустой ленте, фронт на каждой детали.

### Шаг 6: Общий ground (финальный штрих)
- Соедините минус блока питания серво с GND платы узла Q.
- **Проверка:** все массы соединены (платы, БП серво, станок, конвейер).

## 7. Проверка перед включением

- [ ] USB-C кабели — с данными (проверить попыткой прошивки)
- [ ] Серво запитан от отдельного БП, минус соединён с GND платы
- [ ] Конденсатор 470 мкФ на месте, полярность правильная
- [ ] Делитель ACS712 собран (2×10 кОм, строки 20–22), отвод в GPIO4
- [ ] Мультиметр на отводе GPIO4 ≈ 1,2–1,3 В при выключенном станке
- [ ] Потенциометр TCRT5000 настроен (пустая лента = тишина, деталь = вспышка)
- [ ] Датчик тока включён только в низковольтную цепь станка (≤36 В)
- [ ] INMP441 L/R на GND, провода I2S плотные
- [ ] На CAM плате пины узла P свободны от проводки камеры
- [ ] Общий ground: БП серво, все платы, станок, конвейер — все соединены по минусу

## 8. Прошивка и первый запуск

### Определение USB-портов

```bash
ls /dev/ttyUSB*
# Ожидаем: /dev/ttyUSB0, /dev/ttyUSB1, /dev/ttyUSB2
```

### Прошивка каждой платы

```bash
# Узел A
espflash flash --port /dev/ttyUSB0 \
    target/xtensa-esp32s3-none-elf/release/firmware-a

# Узел Q
espflash flash --port /dev/ttyUSB1 \
    target/xtensa-esp32s3-none-elf/release/firmware-q

# Узел P
espflash flash --port /dev/ttyUSB2 \
    target/xtensa-esp32s3-none-elf/release/firmware-p
```

Если плата не видна, зажмите кнопку **BOOT** при подключении.

### Мониторинг UART

```bash
# Через espflash
espflash monitor --port /dev/ttyUSB0

# Или picocom
picocom /dev/ttyUSB0 -b 115200

# Без установки дополнительного ПО
stty -F /dev/ttyUSB0 115200 raw -echo && cat /dev/ttyUSB0
```

### Ожидаемый вывод

**Узел A:**
```
a: boot, run_id=bench-a
a: zero=1638    # зависит от железа
a,bench-a,8000,run
```

**Узел Q:**
```
q: boot, run_id=bench-q
q,bench-q,30,good     # каждые ~400 мс (синтетическое окно до S4)
```

**Узел P:**
```
p: boot, run_id=bench-p
p,bench-p,50,1        # на каждую деталь в зазоре
```

### Проблема с правами

```bash
sudo usermod -aG dialout $USER
# Требуется повторный вход
```

## 9. Постепенный выход на работу

Следуйте поэтапному плану (`docs/eng/decompose/firmware.md`):

### S0 — Тулчейн + мигалка (~2 ч)
- Убедиться в работе espup
- Прошить мигалку для проверки живучести платы
- Запустить `espflash flash-info` для проверки flash (16 MB) и PSRAM

### S1 — Узел A: ADC + калибровка (~3 ч)
- Убедиться в дискретизации ADC1 ~1,6 кГц
- Проверить работу стартовой калибровки нуля
- Проверить формат CSV захвата через UART

### S2 — Узел A: окно → модель → статус (~3 ч)
- Подключить форк (`../fork/microflow` + патч nalgebra)
- Проверить классификацию модели на реальных данных тока
- Убедиться, что гистерезис предотвращает частые переключения

### S3 — Перекрёстная проверка: плата vs хост (~2 ч)
- Конвертировать CSV захвата платы во вход хостового узла
- Запустить хостовый узел A на тех же данных
- Сравнить статусы — несовпадения только на границах окон

### S4 — Узел Q: I2S микрофон (~3 ч)
- Убедиться в дискретизации INMP441 16 кГц
- Вывести окно из 1024 отсчётов через UART
- Убедиться, что тон попадает в ожидаемую спектральную бину

### S5 — Узел Q: Серво + вердикт (~3 ч)
- Проверить тайминги удара серво
- Проверить классификацию модели на реальном звуке тапа
- Убедиться в вердиктах на эталонных деталях (хорошо/брак)

### S6 — Узел P: Счёт деталей (~2 ч)
- Проверить детектирование фронтов TCRT5000
- Убедиться, что debounce 50 мс устраняет дребезг
- Пропустить N деталей, убедиться что count = N

### S7 — Gate + NOTES (~2–3 ч)
- Зафиксировать факты обкатки в `firmware/NOTES.md`
- Написать документ firmware gate
- Принять решение по фазе 2 (UART-мост vs WiFi)

## 10. Фаза 2: UART-мост в MQTT

Когда все три узла начинают выдавать строки статусов, подключите стенд к полному OEE-контуру:

### Запуск брокера + агрегатора + дашборда

```bash
# Терминал 1
./target/debug/broker 1883 &
./target/debug/aggregator --mqtt 127.0.0.1:1883 --ideal-cycle-ms 400 --out windows.csv
./target/debug/oee-dashboard --mqtt 127.0.0.1:1883
```

### Запуск UART-моста

```bash
# Терминал 2 — по одной плате или все три на разных портах
cat /dev/ttyUSB0 | cargo run -p firmware-tools --bin uart-bridge -- 127.0.0.1:1883
```

Мост читает строки статусов из stdin и публикует в `oee/line1/*` в MQTT. По завершении потока он посылает маркеры `{node}/end`, что сигнализирует агрегатору о завершении.

### Проверка без железа

```bash
printf 'a: boot, run_id=bench-a\na,bench-a,1000,run\nq,bench-q,2000,good\np,bench-p,3000,1\n' | \
    cargo run -p firmware-tools --bin uart-bridge -- 127.0.0.1:1883
```

Ожидаемо: `bridge: 6 messages (a+p+q)` и дашборд оживает.

## 11. Безопасность

- **Ограничение напряжения:** Все датчики и проводка — только в цепях ≤36 В. Сеть 220 В недоступна для макетных проводов.
- **Закрепите дрель:** Фиксируйте «станок», чтобы он не двигался во время работы.
- **Предпочтение вентилятору:** Для демо вентилятор безопаснее дрели.
- **Освободите зону серво:** Держите пальцы подальше от позиции тапа, пока серво активно. Палочка не металлическая.
- **Обесточивайте перед переподключением:** Отключайте USB и питание серво перед любыми изменениями в проводке.
- **Расположение ACS712:** Только в низковольтной цепи питания станка, никогда в 220 В.

## Устранение неполадок

| Симптом                                 | Вероятная причина                         | Решение                                                                    |
| --------------------------------------- | ----------------------------------------- | -------------------------------------------------------------------------- |
| Мусор в UART                            | Неправильная скорость или не тот USB-порт | 115200 бод, UART-порт (не OTG)                                             |
| Плата не прошивается                    | В режиме загрузки                         | Зажмите BOOT при подключении                                               |
| Серво дёргается или перезагружает плату | Нет общего ground или конденсатора        | Соедините GND БП серво с GND платы, добавьте 470 мкФ                       |
| Показания узла A плывут                 | Дрейф нуля ACS712                         | Прошивка калибрует при старте — убедитесь, что станок выключен при запуске |
| Узел P считает дребезг                  | Debounce слишком короткий                 | Увеличьте `DEBOUNCE_MS` в `firmware-p`                                     |
| Вердикты узла Q неверны                 | Неправильная фаза I2S                     | Выведите сырое окно, сравните порядок байт с референсом                    |
| Модель расходится с хостом              | Разница квантования                       | Проверьте путь `#[model]`, сравните int8 диапазоны                         |
| «Permission denied» на /dev/ttyUSB*     | Пользователь не в группе dialout          | `sudo usermod -aG dialout $USER`, повторный вход                           |
