## Риски (разд. 11 плана)

- Риск №2 (парсер сложнее ожидаемого) — на этой неделе не касались (парсер —
  неделя 3); спека §2 готова, фактический объём известен со спайка.
- «Слишком хорошие модели» — обработан превентивно: дрейф амплитуды
  (`drift_sigma`) и шум — параметры сценария; тест фиксирует «различимо, но
  не идеально» (средние RMS окон различаются, внутри режима есть разброс).
- Эскалации недели (расхождение кернел/reference, затягивание кернела) —
  не сбылись: бит-в-бит сошёлся, буфер Д4 не понадобился.

## Отступления от декомпозиции

- `golden-gen` — example, а не `src/bin`: dev-зависимости недоступны для bin
  (единственное отклонение от плана Д3, семантика та же).
- §3.3 (FC per-channel + optional bias) — не потребовался для гейта; план Д4
  допускал перенос — уезжает в неделю 3.
- Requant — f32-множитель внутри кернела (спека §3.1), а не константы
  препроцессинга макроса, как у `conv_2d`: кодегену недели 3 достаточно
  пробросить scale/zp и int32-bias. Зафиксировано в [fork/NOTES.md](../../fork/NOTES.md).

## Решение по неделе 3

По плану, перераспределение не требуется: парсер (shape-folding §2.1–2.3,
ранг-3 вход) + кодеген (§4, вызов кернела) + ML-конвейер (модель A, датасет,
parity). Вход готов: спека §2/§4, кернел с API под кодеген, параметризованный
сигнал и датасет-сценарии. Детализация — [decompose/step-3.md](decompose/step-3.md).
