# Сборка и подключение тестового стенда (колея железа)

> Назначение: пошаговая инструкция сборки стенда и подключения компонентов —
> от коробок с платами до готового к обкатке макета. Источник истины по пинам —
> крейт [`board`](../../firmware/board/src/lib.rs) (изменения разводки — только
> там, этот документ за ним следует). Состав закупки —
> [`equipment.md`](./equipment.md) (краткая) и детальная в `kontext/`;
> порядок оживления прошивок — [`decompose/firmware.md`](./decompose/firmware.md).
>
> Стенд: 2× ESP32-S3-DevKitC-1 (N16R8) — узлы A и Q; 1× ESP32-S3-WROOM-1
> N16R8 CAM с OV2640 — узел P + stretch-камера. Собирается по одному узлу за
> сессию (макеток в наличии 1 шт из 4 плановых) — порядок: A → Q → P.

## 1. Состав стенда

| Блок       | Компоненты                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| Платы      | 2× DevKitC-1 N16R8, 1× WROOM-1 N16R8 CAM (OV2640 на борту)                                             |
| Сенсоры    | ACS712-20A (+2×10 кОм делитель), опция INA226, INMP441, TCRT5000 ×2                                    |
| Актуатор   | SG90 + деревянная палочка-таппер (~10–15 см)                                                           |
| Механика   | конвейер 100×350 мм (0–116 об/мин, адаптер — проверить напряжение), «станок»: дрель или вентилятор     |
| Изделия    | гайки/шайбы М5–М8 (~50 шт); «брак» — распил/скол, 10–15 шт, маркировать маркером (ground truth узла Q) |
| Расходники | макетка 830, перемычки M-M/M-F, резисторы, конденсатор 470 мкФ, БП 5 В 2 А, кабели USB-C data          |

## 2. Раскладка стенда (механика)

1. Конвейер — база: детали едут по ленте от «станка» к концу.
2. «Станок» (дрель/вентилятор с болтом на лопасти для дисбаланса) — у начала
   ленты; его питание — от своего БП (≤36 В), в цепь питания ставится датчик
   тока узла A. **Не подключать датчики в сеть 220 В.**
3. Узел A (DevKitC-1 №1) — у станка: измеряет ток привода.
4. Тап-позиция узла Q — на пути детали: серво стучит палочкой по детали,
   микрофон в 2–5 см от точки удара.
5. Узел P (плата CAM) — у конца ленты: TCRT5000 №1 считает детали на сходе,
   №2 (опция) — датчик «конца ленты».

## 3. Питание и общая земля

- Каждая плата — своим USB-C data-кабелем (не charge-only!) в хост: прошивка,
   питание и UART-лог одним кабелем.
- Серво SG90 — **строго от отдельного БП 5 В 2 А**, не от USB платы: стартовый
  ток серво просаживает питание и перезагружает плату. Конденсатор 470 мкФ —
  у ножек питания серво (соблюдая полярность).
- **Общая земля**: минус БП серво соединяется с GND платы узла Q (иначе
  PWM-сигнал не имеет опоры — серво не заработает или будет дёргаться).
- Конвейер — от своего адаптера из комплекта; сверить его выходное напряжение
  с маркировкой мотора до включения.

## 4. Узел A — ток (DevKitC-1 №1)

Подключение ACS712-20A через делитель (S3-пины не толерантны к 5 В):

| Вывод модуля ACS712 | Куда                                            |
| ------------------- | ----------------------------------------------- |
| VCC                 | 5 В (пин 5V платы)                              |
| GND                 | GND платы                                       |
| OUT                 | → делитель: OUT —10 кОм— **GPIO4** —10 кОм— GND |

- Датчик врывается в цепь питания станка **последовательно** (разрыв
  «БП → датчик → станок»), только низковольтная сторона ≤36 В.
- GPIO4 — ADC1: для узла A использовать только ADC1 (ADC2 конфликтует с
  WiFi); диапазон ADC1 = GPIO1–GPIO10.
- Ноль тока ACS712 дрейфует — прошивка делает стартовую рекалибровку
  (`CurrentCalibration::with_zero_counts`): при старте станок выключен.
- Опция INA226 (I2C, без делителя): пины SDA/SCL назначить при выборе ветки и
  завести константами в `board` (сейчас не развёдана).

## 5. Узел Q — звук и таппер (DevKitC-1 №2)

INMP441 (I2S-матрица S3 — любые GPIO):

| Вывод модуля INMP441 | Куда                                            |
| -------------------- | ----------------------------------------------- |
| VDD                  | 3.3 В                                           |
| GND                  | GND                                             |
| SCK (BCLK)           | GPIO12                                          |
| WS (LRCL)            | GPIO13                                          |
| SD (данные)          | GPIO14                                          |
| L/R                  | GND (левый канал; сверить с маркировкой модуля) |

Серво SG90:

| Вывод SG90 | Куда                                      |
| ---------- | ----------------------------------------- |
| Сигнал     | GPIO11 (PWM 50 Гц)                        |
| Плюс       | отдельный БП 5 В (+470 мкФ у ножек)       |
| Минус      | БП **и** GND платы (общая земля, разд. 3) |

Палочка-таппер: шпажка 10–15 см (30 см пружинит), к рогу серво — термоклей
или стяжка; удар — коротким ходом по детали в тап-позиции.

## 6. Узел P — счёт (плата WROOM-1 N16R8 CAM)

TCRT5000 ×2 (в модуле уже компаратор, резисторы не нужны):

| Вывод модуля TCRT5000 | Куда                                                                                             |
| --------------------- | ------------------------------------------------------------------------------------------------ |
| VCC                   | 3.3 В (по маркировке модуля)                                                                     |
| GND                   | GND                                                                                              |
| OUT (счёт)            | GPIO5 — назначение для DevKitC-раскладки; на плате CAM взять пин, свободный от камеры (см. ниже) |
| OUT №2 (опция)        | «конец ленты»; второй свободный пин + константа в `board`                                        |

- Плата CAM несёт OV2640: разводка камеры занимает часть GPIO — перед
  назначением пинов узла P свериться со схемой конкретной платы (у
  CAM-плат разных продавателей раскладка отличается); выбранные пины
  зафиксировать константами в `board` и здесь, в разд. 7.
- Камера сама никуда не подключается (stretch, обкатывается отдельно).

## 7. Сводная таблица пинов (зеркало `board`)

| Узел | Сигнал        | GPIO | Примечание                              |
| ---- | ------------- | ---- | --------------------------------------- |
| A    | ACS712 (ADC1) | 4    | после делителя 2:1; только ADC1         |
| Q    | I2S SCK       | 12   | INMP441                                 |
| Q    | I2S WS        | 13   | INMP441                                 |
| Q    | I2S SD        | 14   | INMP441                                 |
| Q    | Серво PWM     | 11   | питание — отдельный БП + общая земля    |
| P    | IR OUT        | 5    | на плате CAM — пин, свободный от камеры |

Занято платой/чипом (не занимать): GPIO0/3/45/46 (strapping), GPIO19–20
(USB D−/D+), GPIO35–37 (octal PSRAM у N16R8), GPIO43–44 (UART0/консоль).

## 8. Чеклист перед подачей питания

- [ ] Кабели USB-C — data (проверить зарядкой/прошивкой: charge-only не шьёт).
- [ ] У серво: питание от отдельного БП, минус соединён с GND платы, 470 мкФ
      на месте, полярность верна.
- [ ] Делитель на OUT ACS712 собран (2×10 кОм), ADC-вход — GPIO4.
- [ ] Датчик тока — в низковольтной цепи станка (≤36 В), не в 220 В.
- [ ] L/R INMP441 — на GND; I2S-линии короткие, перемычки сидят плотно.
- [ ] На плате CAM выбранные пины узла P не совпадают с камерой и списком
      занятых (разд. 7).
- [ ] Общая земля: БП серво, платы, станок, конвейер — соединены по минусу.

## 9. Первое включение (smoke)

По сессиям декомпозиции обкатки ([`decompose/firmware.md`](./decompose/firmware.md)):

1. **Э0**: тулчейн espup, blinky на каждой плате; `esptool.py flash_id` —
   показать реальный размер flash (16 МБ) и PSRAM (отсечь подмену N8R2).
2. **Э1**: ADC узла A — при выключенном станке ~0 А (рекалибровка нуля);
   мультиметр vs показания на 2–3 токах.
3. **Э4**: I2S узла Q — тон известной частоты у микрофона виден в ожидаемом
   бине спектра (окно ровно 64 мс).
4. **Э5**: серво — одиночный ход таппера (станок и детали на месте, БП
   отдельный); вердикт по звуку на эталонных деталях.
5. **Э6**: узел P — прогон N деталей, счёт = N, дребезг не даёт повторов.

## 10. Безопасность

- Датчики и INA226 — только в цепи ≤36 В (БП станка/конвейера). Сеть 220 В —
  недоступна для монтажа на макетке.
- Дрель — закреплена; вентилятор безопаснее для демонстрации.
- Пальцы не держать в тап-позиции при активном серво; палочка — не металл.
- Перед любым изменением монтажа — отключить USB и БП серво.
