## Д1 (пн, ~3 ч) — движок: парсер flatbuffers

1. По спеке: чтение `CONV_2D` над `(1, T, C)`, сворачивание `Reshape`-цепочки,
   атрибуты stride/padding, 3D-формы тензоров.
2. Юнит-тесты парсера на дампах из спайка недели 1 (фактический граф).
3. Понятные ошибки: неподдерживаемый атрибут → внятное сообщение, а не паника.

Проверка: парсер разбирает все дампы спайка без паник.

## Д2 (вт, ~3 ч) — движок: кодеген

1. Сгенерированный код: буферы под веса/выходы, вызов кернела недели 2.
2. Модель из спайка (необученная) собирается через `#[model]`.
3. Compile-fail тесты: неправильная модель → читаемая ошибка компиляции.

Проверка: `cargo expand` — сгенерированный код читается и понятен.

## Д3 (ср, ~3 ч) — движок: реальный `.tflite` через `#[model]` [гейт]

1. `.tflite` из спайка → `#[model]` → `predict()` на хосте.
2. Parity: те же входы в tf.lite.Interpreter (Python) и в Rust — те же выходы
   (в пределах квантованного допуска).
3. Типичные расхождения: layout весов, порядок requant — сверить со спекой.

Проверка: parity-тест зелёный — главный пункт гейта недели закрыт.

## Д4 (чт, ~2–3 ч) — ML: фичи и датасет узла A

1. `features-cli`: набор фич окна тока (RMS, пик, zero-crossings, спектр) —
   зафиксировать список; тот же крейт потом работает в инференсе (разд. 6).
2. Датасет: `line-simulator` → CSV → фичи → train/val; экспорт фич для Python.
3. Golden-тест фич: Rust vs numpy на одном окне — расхождение 0.

Проверка: датасет сбалансирован по классам; golden-фичи зелёные.

## Д5 (пт, ~3 ч) — ML: обучение и int8

1. Модель A по разд. 6: `Conv1D(8)→AvgPool→Conv1D(16)→AvgPool→FC→Softmax`.
2. Обучение; full-integer int8 (post-training), экспорт `.tflite`.
3. Точность на val; если ~100% → поднять шум в симуляторе (риск разд. 11)
   и пересобрать датасет.

Проверка: метрики зафиксированы; скрипт обучения воспроизводим по seed.

## Д6 (сб, ~3 ч) — ML: parity замкнут

1. `model_a.tflite` → `#[model]` на хосте: предсказания на val совпадают
   с interpreter.
2. Черновая confusion matrix A (разд. 10) — прогоном, без красоты.
3. Parity падает → это блокер недели 4, чинить сейчас.
