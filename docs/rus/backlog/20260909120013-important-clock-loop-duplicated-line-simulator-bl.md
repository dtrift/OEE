# Цикл «пройти события по часам» продублирован 5 раз

- **Серьёзность**: важно
- **Компонент**: line-simulator (затрагивает также nodes, oee-aggregator — тесты)
- **Источник**: ревью `backlog/20260909120000-review.md`, приложение А1, «Важно» №6
- **Локация**: `line-simulator/src/main.rs:67-75`, `taps.rs:88-91`, `belt.rs:65-68`; копии в других крейтах: `nodes/tests/node_pipeline.rs:45-67`, `oee-aggregator/tests/experiment.rs:58-70` (там же продублировано форматирование `{:.4}`)

## Суть

Семантика `event.t_ms <= t` (включительно) реализована вручную в пяти местах, включая формат CSV. При любом изменении (например, фикс f32-времени) рассинхронизация между `main.rs` и тестами других крейтов даст CSV, не совпадающий с «правдой», и заметить это будет трудно.

## Предлагаемое исправление

Экспортировать из lib общий хелпер:

- `Simulator::run(&scenario) -> impl Iterator<Item = Sample>` или
- `write_raw_csv(scenario, seed, writer)`,

и использовать его в `main.rs` и тестах `nodes`/`oee-aggregator`. После этого — интеграционный тест независимости каналов через CLI (см. `20260909120014-important-determinism-test-gaps-line-simulator-bl.md`).
