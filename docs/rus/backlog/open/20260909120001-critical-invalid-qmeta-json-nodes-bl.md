# Невалидный JSON в `publish_q_meta`

- **Серьёзность**: критично
- **Компонент**: nodes
- **Источник**: ревью `backlog/20260909120000-review.md`, приложение А2, «Критично» №1; независимо подтверждено ревьюером агрегатора (А3)
- **Локация**: `nodes/src/mqtt_sink.rs:124-129`

## Суть

В raw-строке `r#"{{\"model\":...}}"#` последовательность `\"` — литеральные бэкслеш + кавычка (в raw-строках Rust нет экранирования). Итоговый payload топика `oee/line1/q/meta`:

```
{\"model\":\"model_q.tflite\",...}
```

Ни один JSON-парсер (включая парсер агрегатора) его не примет. Для сравнения: `publish_a_meta` (`mqtt_sink.rs:116-121`) написан правильно.

## Почему важно

- Топик `q/meta` сейчас никто не парсит, но при первом же потребителе (дашборд, агрегатор, логгер) это мина замедленного действия.
- Ошибка пропущена тестами: `statuses_reach_the_broker_with_the_pinned_shapes` проверяет только meta A, `publish_p_meta` — отдельным тестом, `publish_q_meta` не покрыт вовсе.

## Предлагаемое исправление

Убрать `\` из raw-строки — сделать формат идентичным `publish_a_meta`.

## Тесты

Добавить тест на payload `publish_q_meta` (поймал бы этот баг).
