# CSV собирается целиком в `String` перед записью

- **Серьёзность**: важно
- **Компонент**: line-simulator
- **Источник**: ревью `backlog/20260909120000-review.md`, приложение А1, «Важно» №4
- **Локация**: `line-simulator/src/taps.rs:144-156`, `dataset.rs:58-69`, `belt.rs:109-121`

## Суть

Весь файл сначала накапливается в памяти (для taps-датасета soak-1m это ~1 ГБ строки поверх ~1.2 ГБ `Vec<TapEvent>` с окнами), потом один `write_all`.

Пиковая память ~2× от артефакта + сам вектор событий — для заявленных ~1 ГБ артефактов это влияет на выбор машины.

## Предлагаемое исправление

- Посстрочная запись через `BufWriter` (или `csv::Writer`, как в `write_raw`).
- Опционально: не хранить `samples` в `TapEvent`, а писать окно на лету.

Чинить вместе с `20260909120010-important-unconditional-current-stream-line-simulator-bl.md`.
