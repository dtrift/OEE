# `run_id` не валидируется

- **Серьёзность**: важно
- **Компонент**: nodes
- **Источник**: ревью `backlog/20260909120000-review.md`, приложение А2, «Важно» №3
- **Локация**: `nodes/src/mqtt_sink.rs:8-9` (заявление), `nodes/src/bin/node.rs:61-62` (факт)

## Суть

Комментарий в `mqtt_sink.rs` заявляет: «escaped-free fields (run ids are validated by the CLI)» — но CLI принимает `run_id: String` без валидации. Run_id с кавычкой/бэкслешем ломает JSON во **всех** пейлоадах (`on_status`, `publish_end`).

## Предлагаемое исправление

`#[arg(value_parser = ...)]` в clap, отвергающее `"`, `\` и управляющие символы (или экранирование при форматировании — валидация проще и честнее соответствует doc).

## Тесты

run_id со спецсимволами.
