# Current-стрим генерируется безусловно

- **Серьёзность**: важно
- **Компонент**: line-simulator
- **Источник**: ревью `backlog/20260909120000-review.md`, приложение А1, «Важно» №3
- **Локация**: `line-simulator/src/main.rs:62-75`

## Суть

Цикл синтеза 69.12M сэмплов и `Vec::with_capacity` (~830 МБ на soak-1m) выполняется всегда, даже когда запрошены только `--taps-dataset` / `--belt-events`, которым этот вектор не нужен.

## Почему важно

- На soak-сценариях — сотни МБ памяти и заметное время впустую.
- При нереалистичных `duration_ms` `with_capacity` завершится abort'ом аллокатора вместо внятного сообщения.

## Предлагаемое исправление

Строить `samples` только при `args.out.is_some() || args.dataset.is_some()`.

Чинить вместе с буферизацией CSV (см. `20260909120011-important-csv-buffered-in-memory-line-simulator-bl.md`): условная генерация + стриминговая запись уложат soak-прогоны в память, сопоставимую с размером одного артефакта.
