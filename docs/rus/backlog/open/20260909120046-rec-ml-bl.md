# Рекомендации: ml (exporter, trainer, features-cli)

- **Серьёзность**: рекомендация
- **Компонент**: ml
- **Источник**: ревью `backlog/20260909120000-review.md`, приложение А5, «Рекомендации»

1. **Parity самоссылочен**: writer → interp → microflow — всё in-tree; числовых ожиданий от настоящего TF нет (smoke по TF-файлу проверяет только структуру). Дёшево закрыть раз и навсегда: golden-фикстура из ~10 пар (вход, int8-выход), снятых однократно с `tf.lite.Interpreter` на `conv1d.tflite`, и assert против interp — привяжет числовые конвенции к реальному TFLite без Python в repro-loop.
2. **Compat-режим writer'а**: минимальный файл сознательно microflow-специфичен (rank-3 вход без EXPAND_DIMS, rank-4 вход FC). Если когда-нибудь понадобится погонять файл под настоящим TFLite-runtime — флаг compat-режима, эмитящий обёртки как TF-конвертер.
3. **База путей в тестах**: `#[model(...)]` резолвится от cwd (workspace root), `FIXTURE`/CSV — от manifest dir (`../../ml/...`). Работает, но это известная cargo-ловушка — короткий комментарий в одном из тестов.
