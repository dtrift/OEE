# Мелочи: oee-dashboard

- **Серьёзность**: мелочь
- **Компонент**: oee-dashboard
- **Источник**: ревью `backlog/20260909120000-review.md`, приложение А3, «Мелочи» (№9, 10, 15, 16)

Сводный список мелких замечаний:

1. `state.rs:159` — `history` не ограничен: вердикты ограничены `VERDICT_TICKER` (12), а минутная история растёт без предела (8 байт/минуту — медленно, но непрерывно на длинном многочасовом прогоне). Ограничить, как ленту вердиктов.
2. `main.rs:74` — выход только по `q`; Ctrl-C / Esc не работают: в raw mode Ctrl-C не порождает SIGINT и молча игнорируется. Добавить `Char('c')` с `KeyModifiers::CONTROL` и `Esc`.
3. Фиксированный client id `"oee-dashboard"` (`mqtt.rs:36`) — два экземпляра на одном брокере конфликтуют (mosquitto разорвёт старое соединение). Отметить в доке.
4. `state.rs:122-124` — `finished` срабатывает от первого же `{node}/end`: футер «stream ended» врёт, пока два других узла ещё стримят. Семантика «stream ending» точнее.
