# Заявка «err +0.000» не запинена тестом

- **Серьёзность**: важно
- **Компонент**: oee-aggregator
- **Источник**: ревью `backlog/20260909120000-review.md`, приложение А3, «Важно» №4
- **Локация**: `README.md:252-258`, `docs/eng/week5-gate.md` (заявка); `oee-aggregator/tests/experiment.rs:327-347` (ассерты)

## Суть

README и week5-gate заявляют ошибку `+0.000` на 4 сценариях, но `experiment.rs` ассертит лишь `|err| < 0.05` (OEE) и `< 0.08` (компоненты), `other_seeds` — `< 0.06`. Дрейф до +0.04 пройдёт CI, а README продолжит обещать +0.000. Таблица в доках — ручная выгрузка, не артефакт теста.

## Предлагаемое исправление

Tight-регрессия для seed 42: например, `|err| <= 0.001` на OEE и компонентах (фактически наблюдаемые значения 0.000/−0.001 это допускают), мягкие границы оставить для чувствительностей/других сидов.
