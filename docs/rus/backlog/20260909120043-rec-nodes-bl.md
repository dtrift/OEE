## Согласовать анти-двойной счёт с поясом

`ANTI_DOUBLE_MS=100` выведен из дефолтов пояса (70 < 100 < 320 мс); при смене параметров сценария (например, `pulse_ms + double_gap_ms > 100`) double начнут считаться дважды молча. Либо документировать жёсткую связь с дефолтами `line_simulator::belt`, либо (лучше) переносить порог параметром CLI.
