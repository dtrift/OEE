# Гейт трека Rust-ML — обучение на burn + собственный TFLite-райтер

> Стретч-трек ([декомпозиция](../../tmp/docs/decompose/rust-ml.rus.md)): `.tflite` для узла A
> рождается целиком в Rust — `cargo run` делает train (Burn) → PTQ (свой код) →
> export (свой flatbuffers-райтер) → self-check. Ноль Python в репро-цикле;
> повторный запуск — бит-в-бит тот же файл.

Статус: **реализовано** (ветка `feat/rust-ml`). Решение «основной или параллельный
путь» (Д7.3) остаётся за ревью ментора — `plan.md` (разд. 6) до этого решения
намеренно не тронут.

## Python vs Rust модель

|                   | Python (неделя 3)                 | Rust (этот трек)                            |
| ----------------- | --------------------------------- | ------------------------------------------- |
| train             | Keras (TF-venv)                   | burn 0.21 (NdArray + autodiff), Adam        |
| квантизация       | `tf.lite.TFLiteConverter`         | свой PTQ (`ml/exporter/src/quant.rs`)       |
| экспорт           | конвертер TF                      | свой flatbuffers-райтер (`writer.rs`)       |
| val-сплит         | numpy PCG64, seed 2026            | `StdRng`, seed 2026 (профили классов те же) |
| int8 val accuracy | (зависит от TF-venv)              | 1.0000 (interp и микрофлоу согласны)        |
| размер модели     | 5064 байт (та же архитектура)     | 5064 байта                                  |
| детерминизм       | сиды фиксированы, завязан на venv | бит-в-бит повторные прогоны (sha256)        |
| граф              | 18 операторов + обёртки           | 6 реальных операторов, без обёрток          |
| Python в цикле    | да (venv, установка TF)           | нет                                         |

## Отступления от плана (зафиксированы)

- Портирована логика пер-классового перемешивания, а не биты numpy PCG64:
  состав окон отличается от Python-сплита, профили классов совпадают точно
  (формула порога бит-идентична). Оба трека по отдельности детерминированы.
- Метрики через микрофлоу — отдельным тест-таргетом (`ml_metrics.rs`), а не
  внутри одной команды: `#[model]` компилирует модель на этапе сборки, и cargo
  не пересобирается при смене артефакта (touch-флоу — в `ml/README.md`).
- burn запинован на 0.21.0 (свежая стабильная на Д0); фичи `ndarray`,
  `autodiff`, `std` — без Learner/dataset-инфраструктуры, цикл обучения
  ручной (по анти-скоупу).
- Сгенерированные flatbuffers-биндинги не копируются в экспортер: файл форка
  включается через `#[path]` — один источник истины с `#[model]`.

## Не сделано / в будущее

- `tract` как внешний parity-референс (флаг `--tract`) — не понадобился:
  interp + float-parity покрывают страховочную сеть; вернуться при росте
  набора операторов.
- QAT (анти-скоуп), TF-совместимый граф с обёртками (анти-скоуп).
