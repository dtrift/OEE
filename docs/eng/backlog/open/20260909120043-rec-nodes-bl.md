## Align anti-double counting with the belt

`ANTI_DOUBLE_MS=100` is derived from the belt defaults (70 < 100 < 320 ms); if scenario parameters change (e.g. `pulse_ms + double_gap_ms > 100`), doubles start being counted twice silently. Either document the hard coupling to the `line_simulator::belt` defaults, or (better) pass the threshold as a CLI parameter.
