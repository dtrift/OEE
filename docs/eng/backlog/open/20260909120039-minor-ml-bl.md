# Minor: ml (exporter, trainer, features-cli)

- **Severity**: minor
- **Component**: ml
- **Source**: code review `backlog/20260909120000-review.md` (Russian original), appendix A5, "Minor" (#6-20)

A consolidated list of minor remarks:

1. `ml/exporter/Cargo.toml:11` — the `csv` dependency is used nowhere in the crate. Remove (offline-build is unaffected).
2. `ml/trainer/src/pipeline.rs:235-238` — dead `unused_path_assert` with `#[allow(unused)]`. Remove.
3. `ml/trainer/src/train.rs:40, 73` — `let mut labels` is never mutated; `let _ = &mut labels;` silences the warning instead of dropping `mut`.
4. `ml/exporter/src/quant.rs:313-330` — `#[derive(Default)]` on `Ranges` yields `fc_min = 0.0` (incompatible with `new()` = `±INFINITY`); a future `Ranges::default()` silently produces wrong ranges. Implement `Default` manually or drop the derive.
5. `ml/exporter/src/quant.rs:287-311` — `float_probs` runs the forward twice (`float_forward` + its own chain). Extract the chain or return intermediates.
6. `ml/trainer/src/lib.rs:66-71` — `TaskSpec::name()` infers identity from `num_classes == 4`; a Q spec with 4 classes would log as "a". An explicit task discriminant.
7. `features-cli/src/lib.rs:48-49` — the doc example is stale: "128 samples … at 16 kHz (node Q) … 8 ms", actually Q = 1024 @ 16 kHz = 64 ms; also "provisional … to be pinned by the week-4 lab" — week-4 has shipped (`model_q.tflite` is committed).
8. `ml/README.md:15` — the flag is written `--dataset`, actually `--datasets` (correct in L23).
9. `ml/trainer/src/train.rs:66-71` — epoch loss = the mean of batch means without size weighting: the last partial batch weighs as much as a full one. Worth a comment.
10. `ml/trainer/src/model.rs:163-174` — `windows_to_tensor` silently assumes `CHANNELS == 1`; a future C>1 silently resamples. A `debug_assert!` or a comment.
11. `ml/trainer/src/data.rs:73-77` — `parse::<f32>()` accepts `"nan"`/`"inf"`: one NaN window yields NaN in `asymmetric_params` → scale NaN → `as i64 = 0`, a garbage model silently. Reject non-finite values at load.
12. `ml/exporter/src/graph.rs:117-122` — all `ModelGraph` fields are pub: GraphBuilder validation can be bypassed by assembling the struct by hand → `writer.rs:145` (`timesteps - pool`) can underflow. `pub(crate)` or validate in `write`.
13. `ml/exporter/tests/model_microflow.rs:51-52` — the softmax convention (1/256, −128) is hardcoded in the test; if the writer's convention changes the test fails obscurely. Read it from the model.
14. No numeric parity gate interp↔microflow for **model Q** (for A — ±2 quanta + float parity). The risks are low, but extending `parity_gen`/tests to Q is cheap.
15. `ml/exporter/tests/writer_roundtrip.rs:94-104` — `committed_dummy_file_roundtrips` reads the file twice and compares it with itself (tautology). Gen_dummy is fully seeded — rebuild the dummy in the test and compare bytes with the committed one: a real freshness gate.
