# Recommendations: mqtt-min

- **Severity**: recommendation
- **Component**: mqtt-min
- **Source**: code review `backlog/20260909120000-review.md` (Russian original), appendix A4, "Recommendations"

1. **Extract framing into one private module** (varint + full-packet reading + `MAX_PACKET_SIZE`) and use it in both the client and the broker — closes `20260909120023-important-no-max-packet-size-mqtt-min-bl.md` and the varint reader duplication in one change.
2. **Drain the capture channel and add stats in `bin/broker.rs`** (periodically: messages, clients, disconnects to stdout) — closes the leak (`20260909120024-important-capture-channel-leak-mqtt-min-bl.md`); the broker log in soak is useless today, while transport telemetry is valuable for bench analysis.
3. **Rename the `testing` module**: the broker core → `broker`, the test helpers → `testing`. The bench binary should not import "test infrastructure" as production code.
4. **Document the `Client` contract**: no auto-reconnect/keepalive (today the reconnect contract lives only in the consumers — `MqttSink` and the dashboard loop implement it independently).
